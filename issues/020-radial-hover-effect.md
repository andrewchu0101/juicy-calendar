# 020：radial 選單 hover 效果

**大小：** M　**狀態：** 完成（2026-11-05；M-03 由專案擁有者回報通過）

**成果（What to build）：** 長按左鍵叫出 radial 選單後，被 hover 的那顆球邊界像果凍一樣起伏（樣式 A）；hover 不會讓其他球消失；游標離開該球的固定圓形命中範圍時，該球才被選中並開始拖曳，其他球此時消失；移開即停止起伏；系統設定減少動態效果時不播放；球身維持純色。

**Q-05 決定（2026-11-05）：** 樣式 A「果凍起伏邊界」。單一輪廓，填滿與球相同的純色，起伏的輪廓就是球的新邊界；週期 4 秒；約 3 瓣與 5 瓣的正弦疊加。參考：Pinterest「Wubble 2」（只取概念，改為 2D）；示範頁在工作階段暫存區，不入庫。

**行為決定（2026-11-05）：**
1. hover 只做起伏，其他球保留。
2. 游標離開被 hover 球的範圍的瞬間，該球被選中並開始拖曳，其他球消失。
3. 從一顆球直接移到相鄰另一顆球時，只換 hover，不選中；離開所有球的範圍時，選中最後 hover 的那顆。
4. 游標從球退回圓環中央的圓形區域時，取消 hover、不選中，選單保留、可再 hover（2026-11-05 決定）。中央半徑固定 80 px（先試用；原為圓環半徑−28＝48 px，後改 65 px，使用者仍覺得小）；中央超出圓環半徑 76 px，球之間靠圓心的縫隙也算中央；與球的命中範圍重疊處球優先；圓環半徑不變。
5. 「範圍」是固定的圓形命中半徑（現有 `radialHit`），不隨起伏變動，符合 SRS FR-04「不改變命中判定幾何」。
