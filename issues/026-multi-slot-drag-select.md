# 026：拖曳選取多個時段

**大小：** L（暫估，需求釐清後再定）　**狀態：** 未就緒：等待需求決定（2026-11-05 建立；尚無 PRD／SRS 條文）

**成果（What to build）：** 使用者可以用一個拖曳手勢，一次選取多個時段。具體是什麼樣的結果（一個長區塊、多個區塊、跨幾天）尚未決定。

**來源：** 專案擁有者於 2026-11-05 提出想法：「可以做拖曳選中好幾個時段的功能」。目前只有一句話，沒有行為描述。

**這張票為什麼是需求，不是調整：**
- 現行規則是新事件一律 120 分鐘（Brief NG-03、PRD 規則表「新區塊長度」、`AGENTS.md` 本專案第 7 條）。多時段選取可能與這條衝突。
- 現行建立事件的流程是「選球 → 拖到日曆 → 放開」（AC-01.1）。多時段選取是另一個手勢，需要決定如何與它共存。
- 空白處按下目前會觸發 radial 長按（AC-01.4）；多時段拖曳也從空白處開始，需要決定如何不互相干擾（見票 025 的備註）。
- 拖曳區塊邊緣已可調整長度（AC-01.1、FR-02）；多時段選取要和它的語意分清楚。

**Blocked by：** **專案擁有者決定**（請先回答，再改寫本票）：
1. 選取後產生什麼：一個涵蓋所選範圍的長區塊，還是每個時段各一個區塊（各 120 分鐘？各一個格子的長度？）？
2. 要用什麼手勢：在空白處直接拖曳框選？按住修飾鍵？先選球再拖曳涵蓋多個時段？
3. 「時段」的單位是什麼：半小時格、小時、整天？是否吸附（沿用 30 分鐘吸附？）？
4. 是否可跨天、跨週？超過 10080 分鐘（7 天）怎麼處理（現行區塊長度上限）？
5. 建立後的名稱與顏色：用哪顆球（需不需要先選球）、名稱預設值？
6. 與 Escape、拖曳到日曆外放開（AC-01.2 的拒絕分支）的關係。
7. 要不要寫進 Brief 的目標（G-xx）或 PRD 新增 AC；若與 NG-03 衝突，Brief 的 NG-03 是否修訂。
