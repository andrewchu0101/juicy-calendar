# 003：名稱不得超過 30 字，常數集中

**大小：** M　**狀態：** ready-for-agent（前置票完成後才能開始）

**成果（What to build）：** 事件名稱（雙擊命名、右側面板）與模板名稱都套用同一條規則：去掉前後空白後非空、不超過 30 個使用者看到的字元；超過或空白就拒絕並還原原值。所有可調常數（名稱上限、事件長度上下限、新事件長度）集中到一個模組。

**Blocked by：** 001

**對應 TC／人工：** TC-03；AC-01.3、FR-02；U-11

**驗收指令：** `npm run typecheck`、`npm run lint`、`npm test`、`npm run test:e2e`

**要讀的規格段落：** `docs/03-srs.md` R-3；`docs/05-sds.md` 資料模型（可調常數）與「前端模組」；測試計畫 TC-03
