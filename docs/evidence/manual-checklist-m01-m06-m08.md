# 人工驗收清單：M-01、M-06、M-08（票 016、024）

用途：你在機器前照做，把結果填回「記錄」欄。**這份清單只是步驟，不是結果**；沒做的項目保持「未執行」。通用規則：App 一律正常關閉（不要強制結束，會留下孤兒 `msedgewebview2.exe`）。

## 共同要記錄的環境
Windows 版本與組建（`winver`）、WebView2 Runtime 版本（任務管理員詳細資料或行程命令列路徑）、App 版本與形式（安裝版／免安裝版）、是否為該 WebView2 資料夾的首次啟動、日期時間。

## M-01 乾淨 Windows 安裝（AC-03.1、FR-08、NFR-05；票 016）
前置：乾淨的 Windows（沒裝過本 App；最好沒有 WebView2 以測下載）。安裝檔 `Juicy Calendar_0.1.0_x64-setup.exe`（SHA-256 `2b7eeef6957730609bc9ae42ec286652b135e0398f73abd156e7283f4171b0fa`，私有 draft release `v0.1.0-m01-test`）。
1. 下載後先 `Get-FileHash` 核對雜湊。 記錄：＿＿
2. 執行安裝檔。看到 SmartScreen？按鈕名稱是否與 README 一致（More info → Run anyway／中文介面對應文字）？ 記錄：＿＿
3. 若沒有 WebView2：安裝過程是否連網下載並成功？ 記錄：＿＿
4. 安裝位置（預期 `%LOCALAPPDATA%` 下，不需管理員）。 記錄：＿＿
5. 啟動 → 歡迎畫面 → 建立工作區（選一個空資料夾，不要在雲端同步資料夾）→ 做 TC-01 流程（選球、拖到日曆、2 小時區塊、調整、雙擊命名）。 記錄：＿＿
6. 關閉、再開，區塊仍在。 記錄：＿＿
7. 設定 → 應用程式 → 解除安裝。工作區資料夾與檔案仍在？ 記錄：＿＿
8. README Windows 段落每一步是否照做得通？不通的句子：＿＿
9. Windows 10 1803：有環境才做，沒有就寫「未驗證」。

## M-06 正式監看（NFR-03c；票 024）
做 4 組：免安裝版／安裝版 × 首次啟動／後續啟動。首次啟動可用只作用於該程序的 `WEBVIEW2_USER_DATA_FOLDER` 指到全新資料夾。
1. 依 `docs/06-test-plan.md`「M-06 監看流程」貼入腳本，`$Seconds = 300` 以上，改 `$Exe`。
2. 取樣期間依序做：建立工作區、拖球建立區塊、雙擊命名、拖移、調整長度、切換語言、復原與重做、關閉工作區再開啟。
3. 記錄每個非本機端點：位址、連接埠、行程名稱、首次出現秒數。0 筆＝通過；有任何一筆＝失敗。
4. 腳本結束會正常關閉 App；確認殘留行程為 0。

## `pktmon` 交叉確認（需管理員；看 UDP 與 DNS）
管理員 PowerShell：`pktmon start --capture`，操作 App 約 1 分鐘，`pktmon stop`，`pktmon etl2txt PktMon.etl` 後以行程的遠端位址／DNS 查詢名稱檢視。結果與用途**不要憑位址猜**，未查證就寫「不明」。 記錄：＿＿
